# Final Webots Environments

The final release contains exactly three research-facing worlds generated by
`scripts/build_final_webots_worlds.py` from the verified Stage 5C source.

| World | Footprint | Hazard density | Worker density | Dynamic obstacles |
|---|---:|---:|---:|---|
| `site_small.wbt` | 24×18 m | 0.20 | 0.10 | No |
| `site_medium.wbt` | 26×20 m | 0.35 | 0.20 | No |
| `site_dynamic.wbt` | 28×22 m | 0.45 | 0.30 | Yes |

All retain the verified human-height first-person viewpoint, perspective
projection, RL robot controller, supervisor, live camera, collision geometry,
walkway, workers, equipment, scaffolding, cones, PPE-risk objects, inspection
targets, and lighting. Medium/dynamic add a restricted area and guarded fall
hazard. Dynamic adds a deterministic sinusoidally moving worker.

Generate the worlds:

```powershell
.venv\Scripts\python.exe scripts\build_final_webots_worlds.py
```

Run the independent three-world runtime gate:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\run_final_world_smoke.ps1
```

The gate requires controller startup, mission completion, motor-policy and CV
flags, clean stderr, first-person evidence, and clean shutdown for every world.
The final-world visual validator requires edge density at least 0.0065, dominant
background below 0.75, structured lower-frame content, level vertical geometry,
and a changed initial/final view. The edge threshold is calibrated for the
low-poly Webots geometry and remains high enough to reject blank output.
